## 基础知识落点

前面的课只预告过的知识，到下面这些课要讲清，不能一直留在“后面再学”：

- `double`、平均数、除数不能为零：第 9 课用 `total * 1.0 / n` 讲过；`double` 变量本身还没有专门讲。
- `int` 范围和 `long long`、变量不赋初值、`total =+ i`：第 9 课已讲。
- `bool`：数组查找用 `found=true` 之前。

## 01 基础变量与判断（已拆成第 1 到 3 课）

- 问题：输入一个成绩，怎样输出及格或不及格？
- 核心：输入给变量赋值，表达式计算结果，if 根据真假选一条路。
- 语法：`cin >> score;；score >= 60；if (...) {...} else {...}`
- 追踪：59→不及格；60→及格。7/2 是3，7.0/2是3.5。
- 易错：赋值 = 与比较 == 不同；整数除法不会自动保留小数。

## 02 循环与条件筛选

- 问题：怎样让同一个动作处理一串数字？
- 核心：循环负责逐个取数，判断决定是否处理当前数。
- 语法：`for (int i=1; i<=n; i++)；if (i%2==0)`
- 追踪：n=3 时 i 依次为1、2、3；只输出偶数就只留下2。
- 易错：i 是当前候选数；不要把输出几个数与循环几次混为一谈。

## 03 多分支判断（已做新版）

- 问题：三个结果中只选一个，怎样写？
- 核心：从上往下检查，命中一个分支后跳过后续分支。
- 语法：`if (...) {...} else if (...) {...} else {...}`
- 追踪：95先满足≥90；若先写≥60，就先进入及格分支。
- 易错：后面的条件只有在前面的条件失败后才检查。

## 04 逻辑运算与复合条件（已做新版）

- 问题：两个要求是都满足，还是至少满足一个？
- 核心：&& 要两边都真；|| 至少一边真；! 反转真假。
- 语法：`score>=60 && score<90；a>=90 || b>=90`
- 追踪：75满足前一区间，90不满足；两科95、70满足至少一门优秀。
- 易错：不能写60<=score<90；“至少一个”包含“两者都满足”。

## 05 for循环（已做新版）

- 问题：输出1到n，循环到底怎样走？
- 核心：初始化一次→判断→执行循环体→更新→再次判断。
- 语法：`for (int i=1; i<=n; i++)`
- 追踪：n=3：输出1、2、3；i变成4后判断失败。n=0一次不执行。
- 易错：<=包含端点，<不包含；i++不是在循环体之前执行。

## 06 while循环（已做新版）

- 问题：不知道要重复几次时，怎样决定继续还是停止？
- 核心：每轮先看条件；循环体更新状态，让条件有机会变假。
- 语法：`while (a>1) { a/=2; day++; }`
- 追踪：a=8：8→4→2→1；更新3次，若初始第1天，则答案4。
- 易错：忘记更新可能无限循环；先判断意味着也可能执行0次。

## 07 循环条件筛选（已做新版）

- 问题：一堆候选数中，哪些需要留下？
- 核心：先列举每个候选，再对当前候选做判断。
- 语法：`if (i%2==0)；if (i%10==7)`
- 追踪：1到6检查6个数，留下2、4、6。
- 易错：筛选条件放循环内；没有命中时，本题不输出任何数字。

## 08 累加器（已做新版，和计数器合成第 9 课）

- 问题：怎样把每次得到的数合成一个总和？
- 核心：total 保存已经处理过的数的和；每轮加上本轮数值。
- 语法：`int total=0;；total+=i;`
- 追踪：1到3：total从0变1、3、6。
- 易错：初始化在循环前；最终结果在循环后输出；不要每轮清零。

## 09 计数器（已做新版，和累加器合成第 9 课）

- 问题：怎样统计满足条件的数有几个？
- 核心：count 保存命中次数；每命中一次只增加1。
- 语法：`int count=0;；if (...) count++;`
- 追踪：候选3、6、9：数量3，总和18。
- 易错：count+=i是累加数值，不是计数；没有命中就是0。

## 10 最大值与最小值（已做新版）

- 问题：一串数还没读完，怎样记住目前最大的？
- 核心：best 始终保存已读数据的最大值，新数更大才替换。
- 语法：`cin >> best;；if (x>best) best=x;`
- 追踪：-4→-2→-8：best依次为-4、-2、-2。
- 易错：数据允许负数时不能把0当作答案初值；先读一个后只剩n-1个。

## 11 嵌套循环与图形

- 问题：一行要重复，一整行也要重复，怎么办？
- 核心：外层控制行；每一行里重新执行完整的内层循环。
- 语法：`for (row...) { for (col...) cout<<"*"; cout<<endl; }`
- 追踪：2行3列：每行3次输出，内层一共执行6次。
- 易错：换行放在内层之后、外层之内；三角形的每行数量依赖row。

## 12 一维数组入门

- 问题：读过的数据之后还要用，存在哪里？
- 核心：数组保存一组同类型数据，用下标取出某一个。
- 语法：`int a[100]={};；cin>>a[i];`
- 追踪：n=3时用a[0]、a[1]、a[2]；最后一个是a[n-1]。
- 易错：数组容量100不等于已输入100个；访问越界没有可靠结果。

## 13 数组遍历与简单查找

- 问题：怎么知道某个值有没有出现、出现在哪？
- 核心：逐个比较a[i]和目标；保存的结果决定你在回答什么问题。
- 语法：`found=true；count++；pos=i`
- 追踪：数组5、2、5：找5，存在为真、次数2、首次下标0。
- 易错：i是位置，a[i]是值；首次位置找到后不能被后面覆盖。

## 14 二维数组入门

- 问题：一个表格里的数怎样定位？
- 核心：两个下标共同定位：一个选行，一个选列。
- 语法：`a[i][j]；i<r；j<c`
- 追踪：表格1 2 3 / 4 5 6中，a[1][0]是4；转置后3行2列。
- 易错：用2×3而非只用正方形测试；行列互换后输出形状也变。

## 15 字符与ASCII入门

- 问题：键盘上的数字字符怎样变成可计算的数字？
- 核心：字符符号、字符编码和数值是三件不同的事。
- 语法：`int digit=ch-'0';`
- 追踪：在ASCII兼容环境中，'7'编码55；'7'-'0'的结果为7。
- 易错：仅输入一个数字字符才用这个转换；单个char不能代表一般中文字符。

## 16 string字符串入门

- 问题：怎样访问一个英文单词中的每个字母？
- 核心：string保存字符序列；长度决定可访问字符的下标范围。
- 语法：`word.size()；word[i]；cin>>word;`
- 追踪：cat长度3，下标0、1、2；输入red blue时一次cin只读red。
- 易错：本模块是非空英文单词；最后一个字符是word[n-1]。

## 17 函数定义与调用

- 问题：怎样把一段计算写一次，多次使用？
- 核心：函数接收输入参数，完成计算，把返回值交回调用处。
- 语法：`int square(int x) { return x*x; }；square(3)`
- 追踪：square(3)返回9；调用处可以保存、输出或继续使用9。
- 易错：定义不等于调用；return交回结果，cout才是屏幕输出。

## 18 函数参数与作用域

- 问题：函数里改了x，main里的n为什么没变？
- 核心：这里int按值传递，形参得到副本；需要更新原变量就接收返回值。
- 语法：`n=addOne(n);`
- 追踪：n=4，函数内x++后x为5；只调用不赋值，n仍为4。
- 易错：规则针对本课按值传递，不推广到引用参数；局部变量只能在其作用域内使用。

## 19 结构体入门

- 问题：编号和分数属于同一条记录，怎样一起保存？
- 核心：结构体定义一种记录格式；对象保存具体记录；点号访问成员。
- 语法：`struct Record { int id; int score; };；r.score`
- 追踪：r={101,85}；修改r.score不会改变r.id。
- 易错：比较分数用a.score，输出编号用a.id；类型定义末尾有分号。

## 20 递归入门

- 问题：能不能用更小问题的答案，得到当前答案？
- 核心：递归要有能直接回答的终点、走向终点的小问题、返回时的组合。
- 语法：`if(n==0) return 0;；return n+sum(n-1);`
- 追踪：sum(3)先等sum(2)；到sum(0)=0后，返回值依次为1、3、6。
- 易错：调用向下和结果返回向上都要讲；不能只背“函数调用自己”。

## 21 冒泡排序入门

- 问题：怎样用相邻比较，把一组数排好？
- 核心：从左向右比较相邻两数，顺序不对就交换；一轮把最大值送到末尾。
- 语法：`if(a[j]>a[j+1]) { int t=a[j]; a[j]=a[j+1]; a[j+1]=t; }`
- 追踪：3、1、2→1、3、2→1、2、3；这一轮最大值3到末尾。
- 易错：交换要保留原值；j+1不能越界；相等不必交换。
