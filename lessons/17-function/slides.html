函数定义与调用

学完以后，你能把一段计算起个名字，想用的时候喊一声名字就行。

同一段计算，为什么要写好几遍？

again.cpp（只阅读）
    cout << a * a << endl;    cout << b * b << endl;    cout << c * c << endl;

算三个数的平方，同样的事写了三遍。

要是计算更长，比如判断闰年，写三遍就容易抄错，改一处还得改三处。
办法是：把这段计算写一次，起个名字，要用时喊它的名字。
这样起了名字的一段程序，叫函数。

定义一次，在 main 里调用

square.cpp
int square(int x) {    return x * x;}int main() {    int n = 0;    cin >> n;    int result = square(n);    cout << result << endl;

第 4 到 6 行是定义：写在 main 前面，告诉程序 square 怎么算。

第 11 行是调用：把 n 交给 square，算出来的结果放进 result。

输入 3，屏幕上
9
▶ IDE

一个函数的四个部分

int square(int x) { return x * x; }

int交回来的结果是什么类型
square函数的名字，自己起，用英文
(int x)参数：调用时交进来的数，在函数里叫 x
return把结果交回给调用它的地方

main 也是一个函数：程序从 main 开始运行。

输入 3：调用时发生了什么

第 11 行square(n)，n 是 3跳到 square 里
第 4 行x 拿到 3参数接住交进来的数
第 5 行return 3 * 3把 9 交回去
回到第 11 行square(n) 变成 9result 是 9，第 12 行输出

调用就像把题交给一个专门算平方的同学：你给他 3，他交回 9。
交回来以后，程序接着从调用的地方往下走。

说得清吗？

Q1定义和调用有什么不同？定义说怎么算，调用才真正去算。只定义不调用，函数不运行。

Q2return 和 cout 有什么不同？return 把结果交回调用的地方，cout 才往屏幕上写。

Q3diff(b, a) 和 diff(a, b) 为什么不一样？参数按位置一个对一个，不看外面变量的名字。

先自己说一说，再翻下一步看答案。
