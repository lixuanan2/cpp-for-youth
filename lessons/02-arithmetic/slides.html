读报错：等号左边要是盒子

sum.cpp（只阅读）
    a + b = c;
6:7: error: lvalue required as left
operand of assignment

assignment 就是用等号往盒子里放东西。这句话说：等号左边要有一个盒子。

a + b 是算式，不是盒子，放不进东西。

想把和放进 c，要写成 c = a + b; 和数学里的写法方向不一样。
Dev-C++ 显示的文字可能略有不同。

找错：哪一行有问题？
