有没有：准备一个“找到了吗”的盒子

find.cpp
    bool found = false;    for (int i = 0; i < n; i++) {        if (a[i] == x) {            found = true;        }    }

bool 盒子只放两种值：true（是）或 false（不是）。

先当作没找到，碰到一样的，就改成 true。

循环后：if (found) 输出 YES，否则输出 NO。
先读 n 和 n 个数，最后读 x，都是 -1000 到 1000 的整数。

输入 4，再输入 4 7 4 2，再输入 7
YES

▶ 带这两个数进 IDE

4 7 4 2 里找 7：found 怎么变

a[0] 是 44 == 7 不成立found 还是 false
a[1] 是 77 == 7 成立found 变成 true
a[2] 是 44 == 7 不成立found 还是 true
a[3] 是 22 == 7 不成立还是 true，输出 YES

found 只会从 false 变成 true，没有哪一句把它变回去。
所以只要中间碰到过一次，最后就是 YES。

find.cpp（只阅读）
    bool found = flase;
13:18: error: 'flase' was not declared in this scope

true 和 false 是 C++ 认识的词。拼错了，就成了一个没准备过的盒子名字。

有的编译器还会提示 did you mean 'false'，意思是“你是不是想写 false”。
按提示改成 false 就好。

Dev-C++ 显示的文字和位置可能不一样，还是先找行号和 error。

猜一猜：== 少写了一个等号

find.cpp（只阅读）
        if (a[i] = x) {            found = true;        }

?

4 7 4 2 里找 9，输出什么？

一个等号是“放进去”：每轮把 9 放进 a[i]，数组被改坏了。

屏幕上
YES

放进去的 9 不是 0，if 就当成立，明明没有 9 也说 YES。
能运行、没有 error，答案却错了。比较一定写两个等号。

找错：哪一行把 found 改回去了？

find.cpp（只阅读）
    for (int i = 0; i < n; i++) {        if (a[i] == x) {            found = true;        } else {            found = false;        }    }

这段想回答“有没有”。
4 7 4 2 里找 7，明明有，屏幕上却是 NO。
点出把 found 改回 false 的那一行。
