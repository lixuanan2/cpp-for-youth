输入 I like C++，怎么只剩一个 I？

line.cpp（只阅读）
    string line;    cin >> line;    cout << line << endl;    cout << line.size() << endl;
输入 I like C++
I
1

第 16 课的 cin >> 读 string，碰到空格就停：只读进了 I，后面的留在输入里。

想把一句带空格的话整个读进来，要换一个工具。

getline：一直读到这一行的末尾

line.cpp
    string line;    getline(cin, line);    cout << line << endl;    cout << line.size() << endl;
输入 I like C++
I like C++
10

getline(cin, line) 从键盘读，空格也读进来，读到按回车为止。

10 个字符：I、两个空格、like、C++，空格也算一个字符。

猜一猜：先读 n，再 getline

after.cpp（只阅读）
    int n = 0;    cin >> n;    string line;    getline(cin, line);    cout << line.size() << endl;

输入两行：
3
hello world

屏幕上是几？

cin >> n 只拿走了 3，3 后面的回车还留在输入里。

屏幕上
0

getline 一上来就碰到那个回车，以为这一行结束了：line 是空的，hello world 根本没读到。

▶ 在 IDE 验证

cin.ignore()：先把那个回车扔掉

after_n.cpp
    int n = 0;    cin >> n;    cin.ignore();    string line;    getline(cin, line);    cout << n << " " << line << endl;
输入 3 回车 hello world
3 hello world

cin.ignore() 跳过一个字符，正好是 3 后面的回车。然后 getline 才读到第二行。

记住这个组合：cin >> 读完数，紧接着要 getline，中间先 cin.ignore()。

+ 把两段字拼起来

join.cpp
    string first, last;    cin >> first >> last;    string full = first + " " + last;    cout << full << endl;    cout << full.size() << endl;
输入 Tom Lee
Tom Lee
7

两个 string 用 + 连起来，就接成一个更长的 string。中间想要空格，就把 " " 也拼进去。

数字的 + 是加起来，string 的 + 是接起来。

小测：first 是 "ab"，last 是 "cd"，first + last 是？

substr：从第几个开始，取几个

substr.cpp
    string word;    cin >> word;    cout << word.substr(0, 3) << endl;
输入 hello
hel
h
word[0]
e
word[1]
l
word[2]
l
word[3]
o
word[4]

substr(0, 3)：从下标 0 开始，取 3 个，就是 h、e、l。
第一个数是从哪开始，第二个数是取几个，不是取到哪。

猜一猜：换成 substr(1, 3)

substr.cpp（只阅读）
    cout << word.substr(1, 3) << endl;

还是输入 hello，屏幕上是什么？

屏幕上
ell

从下标 1 的 e 开始，取 3 个：e、l、l。
不是“从第 1 个到第 3 个”。下标从 0 数，个数单独数。

find：这一行里有没有 cat？

find.cpp
    string line;    getline(cin, line);    if (line.find("cat") != string::npos) {        cout << "Found" << endl;    } else {        cout << "Not found" << endl;    }
输入 I have a cat
Found

找不到时 find 交回 string::npos，不等于它就是找到了。固定写法，照着写。

大小写算不同的字：输入 Cat 会输出 Not found。catch 里也有 cat，会输出 Found。

读报错：getline 少写了 cin

line.cpp（只阅读）
    getline(line);
7:5: error: no matching function for call to 'getline' …

抓住两个词：no matching，对不上；getline，就是这一行。

getline 要知道从哪读、读到哪：getline(cin, line)，两样都不能少。

Dev-C++ 显示的文字和位置可能不一样，还是先找行号和 error。
