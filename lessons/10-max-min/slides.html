最大值与最小值

学完以后，一串数读完，程序能告诉你最大的、最小的，还有它排在第几个。

一串数，最大的是谁？

人一眼能看完一串数。程序不行：cin 一次只读一个，读新的时候，旧的已经过去了。

想想打擂台。台上站着到目前为止最强的人，新人上来比一场：
新人赢了，就换新人站上去；没赢，台上的人不动。

程序里的擂主，是一个叫 best 的盒子。
所有数都比完，还站在台上的就是最大值。

新数更大，才换掉 best

max.cpp
    cin >> best;    for (int i = 2; i <= n; i++) {        int x = 0;        cin >> x;        if (x > best) {            best = x;        }    }

第一个数直接站上台，它是目前最大的。

已经读了一个，还剩 n - 1 个，所以 i 从 2 开始。

输入 3，再输入 -4 -2 -8
-2
▶ 在 IDE 打开

n 是 1 到 100，每个数是 -1000 到 1000，都是整数。循环结束后输出 best。

输入 -4 -2 -8：擂台上是谁

第 1 个 -4直接上台best 是 -4
第 2 个 -2-2 > -4 成立换掉，best 是 -2
第 3 个 -8-8 > -2 不成立不换，best 还是 -2
比完了i 变成 4，循环结束输出 -2

每比完一轮，best 都是“已经读到的数里最大的”。
这句话一直成立，读完全部，它就是全部的最大值。

Q2为什么让第一个数上台，不先放 0？0 可能不是输入里的数，会抢走答案；第一个数一定是输入里的。

速查卡

cin >> best;  for (int i = 2; i <= n; i++)

x > best找最大：新数更大才换
x < best找最小：新数更小才换
best = x;把 x 放进 best，不要写反
pos = i;换的时候记下它是第几个
>  >=一样大时，> 留第一个，>= 留最后一个
