逢七拍手：哪些数要拍手？

大家轮流报数。碰到 7 的倍数，或者个位是 7 的数，不许说，要拍手。

7 14 17 21 27 28 35 37

这些数之间，有时差 7，有时差 3，有时只差 1。
上上节课的 i += 2 是一步跨固定的格数，这里 i += 几都不对。
换个办法：每个数都拿来看一眼，再决定要不要它。

for 把数送来，if 决定留不留

even.cpp
    for (int i = 1; i <= n; i++) {        if (i % 2 == 0) {            cout << i << endl;        }    }

if 写在 for 的大括号里面，每一轮都要查一次。
像一个筛子：数一个个落下来，符合条件的才留下。

2
4
6

输入 5：每个数都查一次

i 是 11 % 2 == 0 不成立跳过
i 是 22 % 2 == 0 成立输出 2
i 是 33 % 2 == 0 不成立跳过
i 是 44 % 2 == 0 成立输出 4
i 是 55 % 2 == 0 不成立跳过

i 接着变成 6，6 <= 5 不成立，循环结束。
循环转了 5 轮，if 查了 5 次，留下 2 个。转几轮和留几个，是两回事。
