三种结果，怎么写？

输入一个分数，是 0 到 100 的整数。程序要这样回答：

90 分及以上输出 Excellent
60 到 89 分输出 Pass
低于 60 分输出 Retry

if 和 else 只有两条路：条件成立走一条，不成立走另一条。
现在有三种结果，第三条路放在哪里？

else if：再加一条路

grade.cpp
    cin >> score;    if (score >= 90) {        cout << "Excellent" << endl;    } else if (score >= 60) {        cout << "Pass" << endl;    } else {        cout << "Retry" << endl;    }

在 if 和 else 中间，多写一段 else if，就多了一条路。

输入 75，屏幕上
Pass

程序一道门一道门地问

1if (…)先问第一道门。条件成立就进去，不成立才去下一道门。
2else if (…)前面的门没进去，才会问这一道。可以写好几段。
3else后面没有条件。前面的门全都没进去，就走这里。

进了一道门，这一串后面的门就都不看了。所以这一串最多只走一条路。

读报错：先看行号和 error

grade.cpp（只阅读）
    if (score >= 90); {        ...    } else {
9:7: error: 'else' without a
previous 'if'

9:7 是第 9 行第 7 个字。

error 后面是原因：这个 else 前面没有 if。

可是第 7 行明明有 if。原来它后面多了一个分号，if 到分号就结束了。

这里是编译不过时的报错。报错的那一行没问题，就往上看几行。

读报错：C++ 不认识这个词

grade.cpp（只阅读）
    } elseif (score >= 60) {
9:7: error: 'elseif' was not declared
in this scope

not declared 的意思是：没有定义过这个名字。

C++ 没有 elseif 这个词，要写成 else if，中间有一个空格。

有时一处错误会带出好几条报错。从第一条开始改，改完再编译一次。
Dev-C++ 显示的样子可能略有不同，还是找行号和 error。
