& 写在变量前面，又是什么意思？

where.cpp（只阅读）
    int x = 5;    cout << x << endl;    cout << &x << endl;

0x7ffd5e8c

每个变量在内存里都有一个住的地方，像门牌号，叫地址。&x 就是 x 的地址。

第 25 课的 & 写在类型后面（int &x），是引用；今天的 & 写在变量前面（&x），是取地址。

地址每台电脑、每次运行都可能不一样，不用记它是多少。

指针：一个专门存地址的变量

pointer.cpp
    int x = 0;    cin >> x;    int *p = &x;    cout << *p << endl;    *p = *p + 1;    cout << x << endl;
输入 5
5
6

int *p 准备一个存 int 地址的变量。p = &x，就说 p 指向 x。

*p 是顺着地址找到的那个盒子，也就是 x。改 *p 就是改 x。

指针可以换着指：指向大的那个

pick.cpp
    int a = 0, b = 0;    cin >> a >> b;    int *p = &a;    if (b > a) {        p = &b;    }    cout << *p << endl;

把地址交给函数，也能改外面

swap_ptr.cpp
void swapPtr(int *a, int *b) {    int temp = *a;    *a = *b;    *b = temp;}
swap_ptr.cpp
    swapPtr(&x, &y);    cout << x << " " << y << endl;
输入 5 3
3 5

调用时交的是地址 &x、&y。函数里用 *a、*b 找到外面那两个盒子。

第 25 课的引用和今天的指针，做的是同一件事

int &a引用：函数里直接写 a
swapTwo(x, y)引用：调用时照常写变量
int *a指针：函数里要写 *a
swapPtr(&x, &y)指针：调用时要交地址

只是想让函数改外面的变量，用引用更省事。指针能换着指，下一页就看它和数组的关系。

数组名当地址用，就是第一个盒子的地址

array.cpp（只阅读）
    int a[3] = {4, 7, 2};    int *p = a;    cout << *p << endl;    cout << *(p + 1) << endl;    cout << *(a + 2) << endl;
屏幕上
4
7
2

数组名 a 当地址用，就是 a[0] 的地址，所以 int *p = a; 不用写 &。
p + 1 往后挪一个盒子，*(p + 1) 就是 a[1]。

第 22 课的 sort(a, a + n)：a 是第一个盒子，a + n 是最后一个后面那一格。
平时取数还是写 a[i]，更清楚。
