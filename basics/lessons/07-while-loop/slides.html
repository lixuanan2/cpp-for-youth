读报错：day 怎么不见了？

days.cpp（只阅读）
    while (a > 1) {        int day = 1;        a = a / 2;        day++;    }    cout << day << endl;
main.cpp:8:13: warning: variable 'day' set but not used [-Wunused-but-set-variable]
main.cpp:12:13: error: use of undeclared identifier 'day'

day 是在大括号里准备的，出了大括号就不能用了，所以第 12 行找不到它。

上面的 warning 也在提醒：第 8 行的 day 加了 1，却没人用。
把第 8 行搬到 while 前面就好。放在里面，每轮还会回到 1。

找错：哪一行有问题？

halve.cpp（只阅读）
    while (a > 1) {        a / 2;        cout << a << endl;    }

这段程序想让 a 一直减半。
输入 8，它没有报 error，却一直输出 8，停不下来。
点你认为有问题的那一行。

运行后怎么一动不动？

halve.cpp（只阅读）
    while (a > 1); {        a = a / 2;        cout << a << endl;    }

这段没有 error，能运行。输入 8，屏幕上什么也不出现，程序也不结束。

第 7 行末尾多了一个分号，while 到这里就结束了，循环里什么也没有。
下面的大括号不再属于它，a 永远不变，条件一直成立。删掉分号就好。

说得清吗？

Q1while 的条件在什么时候查？每轮开始前查。成立才进大括号，运行完回来再查。

Q2输入 8，循环转 3 轮，为什么答案是第 4 天？day 从第 1 天开始，转一轮加 1，转完 3 轮就是 4。

Q3程序停不下来，先查什么？查条件里的盒子：大括号里有没有改它，改完条件有没有机会变假。
