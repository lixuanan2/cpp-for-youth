交给函数的，是一份副本

  

    
nmain 的盒子，里面是 4

    
xchange 的盒子，里面是抄来的 4

    
x++改的是 x，n 里还是 4

  

  

    
调用 change(n) 时，程序把 n 盒子里的数抄一份，放进函数自己的盒子 x。

    
就像把作业复印一份交出去：别人在复印件上涂改，你手里的原件不变。
这节课说的 int 参数都是这样传的。

第 12 行change(n)，n 是 44 抄进 x

第 6 行return x交回 5，可是没人接

    
第 13 行cout << n输出 4

  

  
函数结束时，它自己的盒子 x 也跟着没了。
想让 n 变成 5，要把交回来的 5 放回 n 里。

Q1为什么 change(n) 能用到 n 的数，却改不了 n？交进去的是一份副本：数抄过去了，改的是函数自己的盒子。

    
Q2参数写成 int n 和 int x，main 的 n 有什么不同？没有不同：名字一样也是两个盒子，main 的 n 都不会变。

    
Q3用函数 sum(a, b) 算出和，main 里怎么留下这个结果？int s = sum(a, b);，把交回的数放进 main 自己的盒子。

  

  
先自己说一说，再翻下一步看答案。

  







  
速查卡

  
n = addOne(n);

  

    
int 参数交进去的是副本，改它不影响外面

    
n = f(n)想让 n 变，就把结果接回来

    
addOne(n);addOne 只交回结果，没人接，n 就不变

    
作用域变量只在准备它的大括号里能用

    
同名变量不同大括号里的同名变量，是不同的盒子
