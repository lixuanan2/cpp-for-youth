函数参数与作用域

学完以后，你能说清函数里改了什么、外面为什么没变，以及怎样把结果拿回来。

函数里加了 1，n 怎么没变？

change.cpp
int change(int x) {    x++;    return x;}int main() {    int n = 0;    cin >> n;    change(n);    cout << n << endl;

输入 4。change 里明明写了 x++。

屏幕上
4

输出还是 4，不是 5。
这节课就弄清楚为什么。

▶ 在 IDE 打开

交给函数的，是一份副本

调用 change(n) 时，程序把 n 盒子里的数抄一份，放进函数自己的盒子 x。

nmain 的盒子，里面是 4
xchange 的盒子，里面是抄来的 4
x++改的是 x，n 里还是 4

就像把作业复印一份交出去：别人在复印件上涂改，你手里的原件不变。
这节课说的 int 参数都是这样传的。

输入 4：两个盒子各变各的

第 12 行change(n)，n 是 44 抄进 x
第 5 行x++x 变成 5，n 还是 4
第 6 行return x交回 5，可是没人接
第 13 行cout << n输出 4

函数结束时，它自己的盒子 x 也跟着没了。
想让 n 变成 5，要把交回来的 5 放回 n 里。

想改 n，就把结果接回来

add_one.cpp
int addOne(int x) {    return x + 1;}int main() {    int n = 0;    cin >> n;    n = addOne(n);    cout << n << endl;

第 11 行先算右边：addOne(n) 交回 5，再放进左边的 n。

和 n = n + 1 一样，只是加 1 这件事交给了函数。

输入 4
5

名字一样，也是两个盒子

same.cpp
int f() {    int x = 100;    return x;}int main() {    int x = 1;    f();    cout << x << endl;

在大括号里准备的变量，只在这对大括号里能用，这叫它的作用域。

f 里的 x 和 main 里的 x 各有各的地盘，互不打扰。

猜一猜：same.cpp 输出几？

same.cpp
int main() {    int x = 1;    f();    cout << x << endl;

屏幕上是 1 还是 100？

f 运行时，在自己的地盘里准备了一个 x，放进 100，交回 100，没人接。

屏幕上
1

main 里的 x 一直是 1。名字一样，不代表是同一个盒子。

读报错：main 里找不到 x

same.cpp（只阅读）
int f() {    int x = 100;    return x;}int main() {    f();    cout << x << endl;
11:13: error: 'x' was not declared in this scope

x 是在 f 的大括号里准备的，出了 f 就没了。main 里找不到它。

想用 f 算出来的数，就接住它：int x = f();

在线 IDE 显示的文字和位置可能不一样，还是先找行号和 error。

速查卡

n = addOne(n);

int 参数交进去的是副本，改它不影响外面
n = f(n)想让 n 变，就把结果接回来
addOne(n);addOne 只交回结果，没人接，n 就不变
作用域变量只在准备它的大括号里能用
同名变量不同大括号里的同名变量，是不同的盒子
