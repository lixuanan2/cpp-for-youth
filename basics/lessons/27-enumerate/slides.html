枚举

学完以后，遇到“哪些数满足条件”的题，会先想清楚从哪试到哪，再让电脑一个一个试。

12 能被哪些数整除？

我们可能会心算：1、2、3、4、6、12。可要是 n 是 840 呢？心算容易漏。

电脑不怕累：从 1 试到 n，每个都问一句“n 能被它整除吗”，能就记下来。

把所有可能一个一个试一遍，叫枚举。
要先想清楚两件事：从哪试到哪，满足什么条件。

你来当计算机，试一试

try.cpp
#include <iostream>using namespace std;int main() {    int i = ;    cout << 12 % i << endl;    cout << (12 % i == 0) << endl;    return 0;}
第 5 行：12 除以 i 余几2
第 6 行：能整除吗0

从 1 改到 12，哪几个得 1？
你一个个试，就是在做枚举。程序替你试，快得多。

# 自己挑战

各位加起
来是 k

一行读入两个正整数 n 和 k（n 不超过 10000，k 不超过 36）。1 到 n 里，有几个数的各位数字加起来正好是 k？一个也没有就输出 0。比如 21 的各位加起来是 2 + 1 = 3。

输入 30 3，输出
4
输入 100 1，输出
3
输入 9 10，输出
0
▶ 在 IDE 开始写

先自己写，卡住了再翻下一页。

卡住了？一次看一条提示

提示 1从哪试到哪：i 从 1 到 n。满足什么条件：i 的各位加起来是 k。

提示 2拆数位第 7 课倒着输出数字时用过：x % 10 是个位，x / 10 去掉个位，x 变 0 就停。

提示 3不要直接拆 i，先 int x = i; 再拆 x，不然 for 的 i 被改坏了。

密码有几种？

自己定一套规则，让电脑把所有可能都试一遍，数出符合规则的有几种。主题你自己定。

先做到说清从哪试到哪、满足什么条件，再输出有几种。
选你喜欢的三位密码锁、分糖果、排队站位、买文具凑钱，都可以。
还想更厉害把符合的全都列出来，或者让用户输入规则里的数。
