字符与 ASCII 入门

学完以后，程序能处理字母和符号：找下一个字母、转大写，还能写出简单的密码。

a 的下一个字母，程序怎么算？

到现在为止，盒子里放的都是数。可是名字、密码、键盘上的按键，很多是字母和符号。

电脑里其实只存数。每个字母、数字和符号，都有一个固定的编号。
a 的下一个是 b，背后就是编号加 1。

这张“字符和编号”的对照表叫 ASCII。今天学怎么用它。

char：放一个字符的盒子

letter.cpp
    char ch = 'A';    cout << ch << endl;    cout << int(ch) << endl;

一个字符用单引号括起来，'A' 就是字母 A。
直接输出，屏幕上是 A。int(ch) 是把它的编号拿出来看，A 的编号是 65。

char 只放一个英文字母、数字或符号。中文字放不进一个 char。

屏幕上
A
65
▶ 在 IDE 打开

不用背整张表，记住三个起点

'0' 是 48'1' 是 49，一直到 '9' 是 57
'A' 是 65'B' 是 66，一直到 'Z' 是 90
'a' 是 97'b' 是 98，一直到 'z' 是 122

每一段里的编号都是连着的，所以字母和数字字符能加减。
编号不用背，写 'A'、'0' 这样的字符，C++ 就知道是几。

plus.cpp

两行各输出什么？

ch + 1 是拿编号来算：65 + 1，得到一个数。

屏幕上
66
B

第 6 行输出数 66。想看到字母，用 char(…) 把编号变回字符，
第 7 行就是 B。int(…) 和 char(…) 是一对：一个拿编号，一个变回字符。

▶ 在 IDE 验证

'7' 不是 7

'7'键盘上的那个符号，是一个字符
55它在 ASCII 里的编号
7能拿来加减乘除的那个数

用 char 读入 7，盒子里放的是字符 '7'，背后的编号是 55。
要拿它算数，先把它变成真正的 7。

减去 '0'，就变成数

digit.cpp
    char ch = 0;    cin >> ch;    int digit = ch - '0';    cout << digit << endl;

'7' - '0' 就是 55 - 48，等于 7。
数字字符的编号是连着的，离 '0' 有几步，就是几。

这一招只用在一个数字字符上：输入是 0 到 9 中的一个。

读报错：一个字符用单引号

letter.cpp（只阅读）
    char ch = "A";
5:15: error: invalid conversion from 'const char*' to 'char'

invalid conversion 是“没法变过去”。

双引号括起来的是字符串，单引号括起来的才是一个字符。
char 盒子只收一个字符，把 "A" 改成 'A' 就好。

Dev-C++ 显示的文字和位置可能不一样，还是先找行号和 error。
