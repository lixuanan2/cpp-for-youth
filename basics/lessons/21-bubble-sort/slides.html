冒泡排序入门

学完以后，一串乱序的数，程序能一对一对地比，把它们从小到大排好。

一串数，怎样从小到大排好？

4
a[0]
3

2
a[2]
1
a[3]

人一眼就能看出来该怎么排。程序不行，它每次只能比两个数。

想想同学按身高排队：相邻两人比一比，前面的高就换个位置。
从队头一路比到队尾，再从头来一遍……一直比到没人需要换。
这个办法叫冒泡排序：大的数像水里的泡泡，一点点往后冒。

先学一件事：换位置

a 里是 3，b 里是 5。想换成 a 是 5、b 是 3，输入 3 5 时输出 5 和 3。

想象两杯果汁，一杯橙汁、一杯苹果汁，要交换杯子里的东西。
直接把橙汁倒进苹果汁杯？苹果汁就没了。

办法是先拿一个空杯子：橙汁倒进空杯，苹果汁倒进橙汁杯，
再把空杯里的橙汁倒进苹果汁杯。

猜一猜：直接换会怎样？

第三个盒子 temp：先存一份

swap.cpp
    a = b;    b = a;
    int temp = a;    a = b;    b = temp;

?

输入 3 5，a 和 b 是几？

第 7 行把 5 放进 a，a 里原来的 3 被换掉了。

屏幕上
5
5

第 8 行再把 a 放进 b，可 a 已经是 5 了。3 彻底丢了。

加一行 temp，第 8 行改成 b = temp。
temp 就是那个空杯子：先把 a 的 3 存进去，
a 再放心拿 b 的 5，最后 b 从 temp 里拿回 3。

读入两个整数，都是 -1000 到 1000，交换后分两行输出 a 和 b。

▶ 在 IDE 打开

一轮写成代码：j 走一遍

one_pass.cpp
    for (int j = 0; j < n - 1; j++) {        if (a[j] > a[j + 1]) {            int temp = a[j];            a[j] = a[j + 1];            a[j + 1] = temp;        }    }

a[j] 和右边的 a[j + 1] 比，前面的大就交换。
j 只走到 n - 2：最后一个数没有右边的邻居。

一轮比完，最大的数一定到了最后，像泡泡冒上来。

▶ 在 IDE 打开

小测：4 3 2 1 只比一轮，变成什么？

一轮不够，就再来几轮

第 1 轮最大的到最后
第 2 轮剩下的里面最大的，到倒数第二
一共 n - 1 轮前面的都排好了，第一个自然就是最小的

后面排好的不用再比，所以每多一轮，就少比一次。
第 pass 轮（从 0 数）只要比 n - 1 - pass 次。

两层循环：外层数轮，内层比较

sort.cpp
    for (int pass = 0; pass < n - 1; pass++) {        for (int j = 0; j < n - 1 - pass; j++) {            if (a[j] > a[j + 1]) {                int temp = a[j];                a[j] = a[j + 1];                a[j + 1] = temp;            }        }    }

站好的不用再比，所以内层少比 pass 次。
4 个数比 3 轮，一共比较 3 + 2 + 1 = 6 次。

n 是 1 到 20，每个数是 -1000 到 1000。
排好后在一行里输出，每个数后面空一格。

速查卡

int temp = a[j]; a[j] = a[j + 1]; a[j + 1] = temp;

pass < n - 1外层：一共 n - 1 轮
j < n - 1 - pass内层：每轮少比一次，不越界
a[j] > a[j + 1]从小到大；换成 < 就是从大到小
temp交换时先存一份，别把数盖掉
a[n / 2]排好的奇数个数，正中间那个
