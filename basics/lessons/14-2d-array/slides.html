易错点

  
划线的是错的写法，只阅读，不要照抄

  

    
cin >> a[i];cin >> a[i][j];二维数组要两个下标才指到一格

    
a[r][c]a[r - 1][c - 1]行和列都从 0 开始，右下角要各减 1

    
a[j][i]a[i][j]先写行号，再写列号

  

  







  
找错：正方形对，长方形就错

  
column.cpp（只阅读）


    for (int j = 0; j < c; j++) {        int total = 0;        for (int i = 0; i < c; i++) {            total += a[i][j];        }        cout << total << endl;    }

  
这段想求每一列的和。
输入 2 2 和 1 2 3 4，输出 4、6，是对的。
输入 3 2 和 1 2 3 4 5 6，还是输出 4、6，应该是 9、12。
点有问题的那一行。
