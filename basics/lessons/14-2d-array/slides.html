读报错：少写了一个下标

matrix.cpp（只阅读）
            cin >> a[i];
main.cpp:10:17: error: invalid operands to binary expression …

invalid operands：>> 不能用在这两样东西上。cin 不知道怎么往 a[i] 里读数。

a[i] 是一整行，不是一个格子，一个数放不进一整行。
二维数组要两个下标才能指到一格，改成 a[i][j]。

这条报错后面还有很长几行，先看第一行的行号和 error 就够了。

找错：正方形对，长方形就错

column.cpp（只阅读）
    for (int j = 0; j < c; j++) {        int total = 0;        for (int i = 0; i < c; i++) {            total += a[i][j];        }        cout << total << endl;    }

这段想求每一列的和。
输入 2 2 和 1 2 3 4，输出 4、6，是对的。
输入 3 2 和 1 2 3 4 5 6，还是输出 4、6，应该是 9、12。
点有问题的那一行。

测试时别只用行列一样多的表，r 和 c 不一样才能看出写反了。

Q2按行走和按列走，循环有什么不同？外层管行就是按行走，外层管列就是按列走，a[i][j] 不变。
