数组名当地址用，就是第一个盒子的地址

  
array.cpp（只阅读）


    int a[3] = {4, 7, 2};
    int *p = a;
    cout << *p << endl;
    cout << *(p + 1) << endl;
    cout << *(a + 2) << endl;

  

    
数组名 a 当地址用，就是 a[0] 的地址，所以 int *p = a; 不用写 &。
p + 1 往后挪一个盒子，*(p + 1) 就是 a[1]。

    
第 22 课的 sort(a, a + n)：a 是第一个盒子，a + n 是最后一个后面那一格。
平时取数还是写 a[i]，更清楚。
