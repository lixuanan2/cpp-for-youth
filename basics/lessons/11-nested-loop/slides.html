第 6 课我们会用 for 画一行星：循环 4 次，最后换行。

现在“画一行”这件事本身也要重复 3 次。

行数和列数都由输入决定时，复制粘贴就不行了。
办法是：把“画一行”的 for 整段放进另一个 for 的大括号里。

循环里面放循环

rect.cpp
    for (int row = 1; row <= rows; row++) {        for (int col = 1; col <= cols; col++) {            cout << "*";        }        cout << endl;    }

这叫嵌套循环。row 是第几行，col 是这一行的第几列。
rows 和 cols 是 1 到 10 的整数，一行读入，用空格隔开。
