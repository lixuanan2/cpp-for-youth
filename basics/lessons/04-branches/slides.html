读报错：先看行号和 error

  
grade.cpp（只阅读）


    if (score >= 90); {
        ...
    } else {

  
main.cpp:7:21: warning: if statement has empty body [-Wempty-body]
main.cpp:9:7: error: expected expression

  

    

      
先看 error：第 9 行第 7 个字，else 这里看不懂，本来应该有一句代码。

      
再看上面的 warning（警告）：第 7 行的 if 后面是空的。

      
原来 if 后面多了一个分号，if 到这里就结束了，else 前面没有 if 了。

      
报错的那一行没问题，就往上看几行。warning 不会挡住运行，可它常常指着真正的错。

    

  

  







  
读报错：C++ 不认识这个词

  
grade.cpp（只阅读）


    } elseif (score >= 60) {

  
main.cpp:9:7: error: use of undeclared identifier 'elseif'
main.cpp:9:27: error: expected ';' after expression

  

    

      
undeclared identifier 是“没准备过的名字”。C++ 不认识 elseif，把它当成了一个名字。

      
C++ 没有 elseif 这个词，要写成 else if，中间有一个空格。

      
第二条是第一条带出来的。一处错误常会带出好几条报错：
从第一条开始改，改完再运行一次。
