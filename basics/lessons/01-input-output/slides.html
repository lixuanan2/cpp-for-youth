报错不可怕：先看第一行

  
hi.cpp（只阅读）


    cout << "Hi" << endl
    return 0;

  
main.cpp:5:25: error: expected ';' after expression
    cout << "Hi" << endl
                        ^
                        ;
  1 error generated.

  

    

      
这是 cpp.sh 下面 compilation 那一栏。先看第一行。

      
main.cpp:5:25 是文件名、第 5 行、第 25 个字。

      
error 后面是原因。expected 是“本来应该有”：这一句后面本来应该有分号。

      
下面把第 5 行抄了一遍，^ 指着位置，; 是它建议补上的。
最后一行说一共有几个错。

    

  

  







  
读报错：这个盒子没准备

  
box.cpp（只阅读）


    int a = 3;
    cout << b << endl;

  
main.cpp:6:13: error: use of undeclared identifier 'b'

  

    

      
6:13 是第 6 行第 13 个字。

      
undeclared 的意思是“没有准备过”，identifier 是名字。

      
程序里只准备了 a，没有 b。

      
名字写错一个字母，也会出现这个报错。
