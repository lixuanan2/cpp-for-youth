每一行在做什么？

hello.cpp
#include <iostream>using namespace std;int main() {    cout << "Hello, World!" << endl;    return 0;}

开头两行是准备工作：告诉编译器，我们要用输入输出的功能。

main 是程序开始的地方。程序从大括号里的第一行往下走，走到 return 0 结束。

我们的代码写在大括号里。cout 把东西送到屏幕，<< 像一个箭头，指向 cout。

框架不用背，起始程序里都帮你写好了。

endl 是换行，像写字时按一下回车。没有它，后面的字会紧跟在同一行。

猜一猜：加不加引号一样吗？

有引号

cout << "age";

age

没引号

cout << age;

12

盒子 age 里放着 12。引号里的是文字，原样显示。
没有引号的是盒子的名字，显示盒子里的数。

盒子 age 里放着 12。两边各输出什么？

用 << 把文字和盒子连起来

intro.cpp

屏幕上
I am 12

一个 cout 后面可以接好几段，每一段前面都写 <<，它们会按顺序送到屏幕。

"I am " 的引号里，am 后面有一个空格。少了它，屏幕上就会连成 I am12。

报错不可怕：看 error 后面

hi.cpp（只阅读）
    cout << "Hi" << endl    return 0;
error: expected ';' before 'return'

expected 的意思是“本来应该有”。这句话说：return 前面本来应该有分号。

真正少分号的是第 5 行。

这种错误，编译器可能指到第 5 行，也可能指到下一行。
报错那一行看不出毛病，就看看它的上一行。

读报错：这个盒子没准备

box.cpp（只阅读）
    int a = 3;    cout << b << endl;
6:13: error: 'b' was not declared
in this scope

6:13 是第 6 行第 13 个字。

not declared 的意思是：这个名字没有准备过。

程序里只准备了 a，没有 b。

名字写错一个字母，也会出现这个报错。Dev-C++ 显示的文字可能略有不同。

找错：哪一行有问题？

点你认为有问题的那一行。
