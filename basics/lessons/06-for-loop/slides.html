输出 1 到 100，怎么写？

三行就够了

hundred.cpp
    cout << 1 << endl;    cout << 2 << endl;    cout << 3 << endl;    cout << 4 << endl;    cout << 5 << endl;
    for (int i = 1; i <= 100; i++) {        cout << i << endl;    }

输出 1 到 5，写 5 行还能忍。输出 1 到 100，就要写 100 行。
要是数到几由输入决定，写程序的时候根本不知道该写多少行。
这些行长得差不多，只有数字在变。

这就是 for 循环：上面加一行 for，cout 里的数字换成 i，另外几行删掉。
大括号里写要重复做的事，圆括号里写重复到什么时候。
i 是一个盒子，每轮装着不同的数。

圆括号里有三段

for (int i = 1; i <= 100; i++)

起点准备盒子 i，先放进 1。这件事只做一次。
条件每一轮开始前检查。成立就继续，不成立就结束。
更新大括号运行完以后做，让 i 换成下一个数。

i++ 是 i = i + 1 的简写，意思是把盒子里的数加 1。
三段之间用两个分号隔开，不是逗号。

一步步看：输入 3，第一轮

读报错：i 怎么不见了？

count.cpp（只阅读）
    for (int i = 1; i <= 3; i++); {        cout << i << endl;    }
main.cpp:6:17: error: use of undeclared identifier 'i'
main.cpp:5:33: warning: for loop has empty body [-Wempty-body]

undeclared 的意思是：这里没有准备过这个盒子。

第 6 行没写错。下面的 warning 指着第 5 行末尾：for 后面是空的，那里多了一个分号。

分号让 for 到这里就结束了，下面的大括号不再属于它。
for 里准备的 i 只能在循环里用，所以第 6 行找不到 i。删掉分号就好。

找错：哪一行有问题？

five.cpp（只阅读）

速查卡

for (int i = 1; i <= n; i++) { … }

int i = 1起点：只运行一次
i <= n条件：每轮先查，成立才进大括号
i++更新：大括号运行完以后加 1
i--  i += 2每轮减 1，每轮加 2
<=  <<= 包含 n，< 不包含 n
