圆括号里有三段

  
for (int i = 1; i <= 100; i++)

  

    
起点准备盒子 i，先放进 1。这件事只做一次。

    
条件每一轮开始前检查。成立就继续，不成立就结束。

    
更新大括号运行完以后做，让 i 换成下一个数。

  

  
i++ 是 i = i + 1 的简写，意思是把盒子里的数加 1。
三段之间用两个分号隔开，不是逗号。

速查卡

  
for (int i = 1; i <= n; i++) { … }

  

    
int i = 1起点：只运行一次

    
i <= n条件：每轮先查，成立才进大括号

    
i++更新：大括号运行完以后加 1

    
i--  i += 2每轮减 1，每轮加 2

    
<=  <<= 包含 n，< 不包含 n
