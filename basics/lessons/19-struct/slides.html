结构体入门

学完以后，一个同学的编号和分数能装进同一张“卡片”，一起存、一起拿。

编号和分数，分开放容易乱

一个同学有编号，也有分数。用两个数组：id[i] 放编号，score[i] 放分数，只要 i 对齐就行。

可是两样东西分在两处，挪一个忘了挪另一个，编号就对不上分数了。
要是还有年龄、班级，数组就更多了。

更自然的办法：给每个同学做一张卡片，卡片上写着编号和分数。
C++ 里做这种卡片，用 struct（结构体）。

先画卡片的样子，再做一张

record.cpp
struct Record {    int id;    int score;};int main() {    Record r = {101, 85};    cout << r.id << endl;    cout << r.score << endl;    return 0;

第 4 到 7 行画出卡片的样子：叫 Record，上面有 id 和 score 两格。

第 10 行照这个样子做一张卡片 r，按顺序填上 101 和 85。

四个要点

struct Record新的类型叫 Record，用起来像 int
int id; int score;卡片上的格子，叫成员
};大括号后面有分号，别漏
r.score点号：取 r 这张卡上的 score 格

struct 写在 main 前面，main 里就能用 Record 做卡片。
r.score 用起来和普通变量一样：能读入、能输出、能计算。

一叠卡片：结构体数组

top.cpp
    int best = 0;    for (int i = 1; i < n; i++) {        if (s[i].score > s[best].score) {            best = i;        }    }    cout << s[best].id << endl;

前面先用 Record s[100]; 准备一叠卡片，再用 cin >> s[i].id >> s[i].score; 读入 n 张。

s[i] 是下标为 i 的卡片，s[i].score 是它的分数。

best 记的是那张卡的下标，最后输出那张卡的编号。

读报错：大括号后面少了分号

record.cpp（只阅读）
struct Record {    int id;    int score;}
main.cpp:7:2: error: expected ';' after struct

struct 的大括号和 if、for 的不一样，后面要跟一个分号。

在第 7 行的 } 后面加上分号就好。

找错：哪一行有问题？

higher.cpp（只阅读）
    if (a.id > b.id) {        cout << a.id << endl;    } else {        cout << b.id << endl;    }

这段想输出分数高的编号。
输入 101 85 102 90，输出 102，对了。
输入 101 90 102 85，还是 102，错了。
点你认为有问题的那一行。
