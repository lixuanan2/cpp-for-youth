total 是一个存钱罐

sum.cpp
    int total = 0;    for (int i = 1; i <= n; i++) {        total += i;    }    cout << total << endl;

存钱罐先是空的。每一轮把 i 放进去，罐子里的钱越来越多。
total += i 就是 total = total + i，第 6 课学过。

输入 3，屏幕上
6
▶ 在 IDE 打开

输入 3：罐子里的钱怎么变

i 是 10 + 1total 变成 1
i 是 21 + 2total 变成 3
i 是 33 + 3total 变成 6
i 是 44 <= 3 不成立循环结束，输出 6

total 里放的，一直是“到目前为止的和”。
每一轮的 total 都接着上一轮，所以它要活得比循环长。

三句话，三个位置

循环前面int total = 0;
准备空罐子，只做一次。
循环里面total += i;
每轮放进一个数。
循环后面cout << total;
全部放完才打开看。

累加的错误，大多是这三句放错了位置。
写完先看一眼：这句该运行一次，还是每轮都运行？

猜一猜：清零写进了循环

sum.cpp
    int total = 0;    for (int i = 1; i <= n; i++) {        total += i;    }    cout << total << endl;
    int total = 0;    for (int i = 1; i <= n; i++) {        total = 0;        total += i;    }    cout << total << endl;

?

输入 3，屏幕上是几？

每一轮先把罐子倒空，再放进这一轮的 i。

屏幕上
3

前面放的都被倒掉了，最后只剩 i 是 3 的那一次。
准备罐子只做一次，要写在循环前面。

位置和累加一样：循环前准备，循环里加，循环后输出。

猜一猜：平均分是多少？

average.cpp
    cout << total / n << endl;

?

3 个成绩 80 85 86，total 是 251，n 是 3。
屏幕上是几？

251 除以 3 约等于 83.67。
可是 total 和 n 都是 int。

屏幕上
83

这是第 2 课的整数除法：两个 int 相除，小数被去掉了。
总分是整数没问题，问题出在除的时候。

▶ 在 IDE 验证

先乘 1.0，再除

average.cpp
    cout << total * 1.0 / n << endl;

total * 1.0 得到一个带小数的数，再除就不会丢掉小数。
第 2 课的 7.0 / 2 也是这个道理。

屏幕上
83.6667

n 要从 1 开始。总共 0 个人时不能算平均分：
整数除以 0 没有正确答案，程序可能直接退出，也可能给出错的数。

n 是 1 到 100，成绩是 0 到 100，都是整数。

读报错：同一个盒子准备了两次

sum.cpp（只阅读）
    int total = 0;    int total = 0;
main.cpp:8:9: error: redefinition of 'total'
main.cpp:7:9: note: previous definition is here

redefinition 的意思是：这个盒子已经准备过了，又准备了一次。下面的 note 指着第 7 行，第一次准备在那里。

同一层大括号里，一个名字只能准备一个盒子。
想再用它，直接写 total，前面不用再写 int。删掉第 8 行就好。

忘了放 0：没有 error，答案却怪

sum.cpp（只阅读）
    int total;    for (int i = 1; i <= n; i++) {        total += i;    }

盒子准备好了，可是没放东西。里面是什么，没人知道。

输入 3，有时碰巧是 6，有时是 -148750242 这样的怪数，换一台电脑又不一样。
所以程序碰巧答对，不代表它是对的。
盒子准备好就放一个数，这样的错误就不会有。

找错：哪一行有问题？

sum.cpp（只阅读）
    int total = 0;    for (int i = 1; i <= n; i++) {        total =+ i;    }    cout << total << endl;

这段程序想算 1 到 n 的和。
它没有报 error，可是输入 3，屏幕上是 3，不是 6。
点你认为有问题的那一行。

罐子太小：int 装不下

big.cpp
    long long total = 0;    for (int i = 1; i <= n; i++) {        total += i;    }    cout << total << endl;

常见的 int 最大约 21 亿，1 到 100000 的和超过了它。
用 int 时结果不可靠：我们试的电脑上是 705082704，换一台可能不同，也没有 error。
long long 是更大的整数盒子，和有可能很大时用它。

输入 100000，屏幕上
5000050000
