vector 入门

学完以后，事先不知道有多少个数也能全存下来：来一个，往后面放一个。

读到 0 才停，要准备多少个盒子？

第 12 课的数组要先写好大小：int a[100]。题目先告诉我们 n，就知道要存几个。

可要是题目说“一直读，读到 0 才停”，事先不知道会有几个数。
准备 100 个，万一来了 200 个呢？

C++ 有一种会自己变长的数组，叫 vector。
来一个数，就往它后面放一个，它自己会长出新的位置。

push_back：往后面放一个

reverse.cpp
    vector<int> v;    int x = 0;    cin >> x;    while (x != 0) {        v.push_back(x);        cin >> x;    }    int n = v.size();

vector<int> v 准备一个放整数的 vector，一开始是空的。

v.size() 是现在有几个，v[i] 和数组一样，从 0 开始。

输入 3 1 4 0
4
1
3

后面和第 12 课一样，i 从 n - 1 倒着走，输出 v[i]。

开头要加 #include <vector>。最后的 0 只用来停，不放进去。

输入 3 1 4 0：v 一点点变长

读到 3push_back(3)v 是 3，size 是 1
读到 1push_back(1)v 是 3 1，size 是 2
读到 4push_back(4)v 是 3 1 4，size 是 3
读到 00 != 0 不成立不放，循环结束

新来的总是接在最后面：v[0] 是 3，v[1] 是 1，v[2] 是 4。
读完以后，v.size() 就是一共存了几个。

小测：输入 3 1 4 0，读完后 v.size() 是几？

猜一猜：一上来就输入 0

事先知道有几个，用数组或 vector 都行；不知道有几个，用 vector 更方便。

vector 也能 sort

sorted.cpp
    sort(v.begin(), v.end());

数组写 sort(a, a + n)，vector 写 sort(v.begin(), v.end())。
begin() 是开头，end() 是最后一个的后面，意思和 a、a + n 一样。

这也是一个固定写法，照着写。开头要同时加 #include <vector> 和 #include <algorithm>。

1 2 3 4

v[i] 越界，和数组一样危险

out.cpp（只阅读，不要运行）
    vector<int> v;    v.push_back(3);    v.push_back(1);    cout << v[2] << endl;

v 里只有 2 个数，下标是 0 和 1，没有 v[2]。
vector 会长，但不是你一取它就长：本课用 push_back 让它变长，取 v[i] 不会多出一个。

取 v[2] 没有 error，结果说不准，和第 12 课的数组越界一样。下标要小于 size()。

读报错：size 后面少了括号

count.cpp（只阅读）
    int n = v.size;
main.cpp:13:15: error: reference to non-static member function must be called; did you mean to call it with no arguments?

抓住后半句：call it with no arguments，不带参数调用它，也就是加一对空括号。

size() 是 vector 自带的函数，要加括号才会运行，交回有几个。
写成 v.size() 就好。push_back(x) 也一样，括号不能少。

找错：哪一行的顺序反了？

输入 3 1 4 0，应该是 3 和 8，屏幕上却是 3 和 5。
