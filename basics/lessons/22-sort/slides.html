它比冒泡快得多，用起来只要一行。

今天先把 sort 当成一个固定写法记住，会用、用对就行。

sort(a, a + n)：把前 n 个排好

sort.cpp
#include <iostream>#include <algorithm>using namespace std;
sort.cpp
    sort(a, a + n);

用 sort 要在开头加 #include <algorithm>，每次都加上。
读入以后写这一行，a 的前 n 个数就从小到大排好了。

n 是 1 到 100，每个数是 -1000 到 1000，都是整数。

输入 4，再输入 3 1 4 2
1 2 3 4
▶ 在 IDE 打开

a 和 a + n 说的是一段范围

3
a[0]
1
a[1]
4
a[2]
2
a[3]

a 说的是从 a[0] 开始。
a + n 说的是到 a[n] 前面停，a[n] 自己不算。

所以 sort(a, a + n) 排的正好是 a[0] 到 a[n - 1]，就是读进来的 n 个数。
和 for 里的 i < n 一样：从 0 开始，到 n 前面停。

猜一猜：写成 a + n - 1

?

输入 4，再输入 3 1 4 2，屏幕上是什么？

范围到 a[3] 前面停，只排了前 3 个：3 1 4 排成 1 3 4。

屏幕上
1 3 4 2

最后的 2 没参加排序，还留在最后。
想成 i < n 就不会多减：要排 n 个，就写 a + n。

从大到小：再加一个 greater

desc.cpp
    sort(a, a + n, greater<int>());

greater 是“更大的在前面”。<int> 说排的是整数，最后的 () 不能少。
这一整串先当固定写法记住，照着写。开头还要加 #include <functional>。

另一个办法是照常从小到大排，再从 a[n - 1] 倒着输出，第 12 课学过。
