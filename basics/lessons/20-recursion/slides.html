递归入门

学完以后，你能让一个函数调用自己，把大问题一步步拆成小问题来解决。

排了一条长队，你是第几个？

你看不到队头，只能问前面的人：“你是第几个？”
前面的人也不知道，于是再问他前面的人……

一直问到第一个人。他不用问，直接说：“我是第 1 个。”
答案再一个个传回来：每人在听到的数上加 1，告诉后面的人。

每个人做的事都一样：问前面的人，再加 1。只有第一个人能直接回答。
程序里，一个函数调用自己来解决更小的同一个问题，叫递归。

1 加到 n：先算 1 加到 n - 1

sum.cpp
int sum(int n) {    if (n == 0) {        return 0;    }    return n + sum(n - 1);}

1 加到 3，就是 3 加上“1 加到 2”。sum 在第 8 行调用了自己。
n 是 0 时，和就是 0，不用再问。n 是 0 到 20 的整数。

输入 3，屏幕上
6
▶ 在 IDE 打开

写递归，要想清三件事

终点什么时候能直接回答？n 是 0 时，返回 0。
更小的题交给自己去算的，要比现在小：sum(n - 1)。
组合拿到小题的答案后怎么用：n + 小题答案。

更小的题一步步往终点走，最后总能走到。
少了终点，或者题目没有变小，就会一直调用下去。

sum(3)：先一层层往下问

sum(3)要算 3 + sum(2)先等 sum(2)
sum(2)要算 2 + sum(1)先等 sum(1)
sum(1)要算 1 + sum(0)先等 sum(0)
sum(0)到终点了直接返回 0

前三层都还没算完，都停在 + 号那里等着。
直到 sum(0) 给出答案，才开始往回算。

再一层层往回算

sum(1)1 + 0返回 1
sum(2)2 + 1返回 3
sum(3)3 + 3返回 6，main 输出 6

往下问的时候，每层只留下要做的加法；往回传的时候，才真正算出来。
和排队一样：先一路问到队头，再一路把答案传回来。

1 乘到 n：终点要换一个数

fact.cpp
int fact(int n) {    if (n == 0) {        return 1;    }    return n * fact(n - 1);}

4 × 3 × 2 × 1 = 24。组合换成了乘法。
终点返回 1：乘上 1 不会改变结果。n 是 0 到 12 的整数。

输入 4，屏幕上
24

删掉终点会怎样？

sum.cpp（只阅读，不要运行）
int sum(int n) {    return n + sum(n - 1);}

sum(3) 问 sum(2)，sum(2) 问 sum(1)，再问 sum(0)、sum(-1)、sum(-2)……
没有人能直接回答，就一直问下去。

每问一层，电脑都要记下“还等着做的加法”。记的东西越来越多，
很快就装不下，程序出错退出，什么答案也没有。递归一定要有终点。

读报错：调用自己时，名字写错了

sum.cpp（只阅读）
int sum(int n) {    …    …    …    return n + summ(n - 1);
main.cpp:8:16: error: use of undeclared identifier 'summ'; did you mean 'sum'?

递归是用名字喊自己。名字多打了一个 m，程序就找不到这个函数。

把 summ 改回 sum。这回 cpp.sh 猜对了：did you mean 'sum'? 就是“你是不是想写 sum”。

输入 3，输出

1+1+1、1+2、2+1输入 1，输出
1
输入 4，输出
5
▶ 在 IDE 开始写

先自己写，卡住了再翻下一页。

卡住了？一次看一条提示

提示 1想最后一步：从第 n - 1 级上 1 级，或者从第 n - 2 级上 2 级。

提示 2所以 n 级的走法 = n - 1 级的走法 + n - 2 级的走法。

提示 3这次要两个终点：1 级有几种走法？2 级有几种？

提示 4在纸上画 ways(4)：它要 ways(3) 和 ways(2)，ways(3) 又要 ways(2) 和 ways(1)。从终点往回加，就是 5。
