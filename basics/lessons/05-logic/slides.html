读报错：&& 后面少了什么？

  
score.cpp（只阅读）


    if (score >= 60 && < 90) {

  
main.cpp:7:24: error: expected expression

  

    

      
expected expression 的意思是：这里本来应该有一个算式。

      
< 的前面缺了要比较的数。要写成 score < 90。

      
这道题里，&& 的两边都要写成完整的比较。

    

  

  







  
读报错：括号要包住整个条件

  
score.cpp（只阅读）


    if (score >= 60) && (score < 90) {

  
main.cpp:7:25: error: expected identifier

  

    

      
if 的条件写在一对圆括号里。第一对括号关上，条件就结束了。

      
后面的 && 不在条件里，程序就看不懂了。7:25 指着 && 后面的左括号。

      
要在最外面再包一层：if (score >= 60 && score < 90) {

说得清吗？

  

    
Q1&& 和 || 差在哪里？&& 要两边都成立，|| 只要有一边成立。

    
Q2为什么不能写 60 <= score < 90？程序先算左边得到 0 或 1，再拿它和 90 比，不是数学里的意思。

    
Q3!(score >= 60) 的括号为什么不能少？少了括号，! 只管到 score，不是反转整个比较。

  

  
先自己说一说，再翻下一步看答案。

  







  
速查卡

  

    
条件1 && 条件2并且：两边都成立才算成立

    
条件1 || 条件2或者：有一边成立就算成立

    
!(条件)不：真变假，假变真

    
x >= 60 && x < 90区间要拆成两个完整的比较

    
a && (b || c)要先算的部分用圆括号包起来
