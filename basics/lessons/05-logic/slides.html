一个比较不够用

输入一个分数，是 0 到 100 的整数。
分数在 60 到 89 之间，就输出 Yes，否则输出 No。

59太低了，输出 No
75在中间，输出 Yes
90太高了，输出 No

score >= 60 只管住了下面，90 分也能通过。
这个分数要同时满足两件事，一个比较写不下。

猜一猜：照数学课这样写

&&：两件事都要成立

score.cpp
    if (60 <= score < 90) {        cout << "Yes" << endl;    } else {        cout << "No" << endl;    }
    if (score >= 60 && score < 90) {        cout << "Yes" << endl;    } else {        cout << "No" << endl;    }

?

输入 95，你觉得输出什么？

程序从左往右算。60 <= 95 成立，这一段算出来是 1。
接着算的是 1 < 90。

屏幕上
Yes

1 小于 90，所以成立。输入 50 也一样，0 小于 90。
这样写，输入什么都是 Yes。

这句语法上没错，所以能编译运行，只是意思和数学不一样。编译器可能给一个警告，也可能不说话，这句不要照抄。

两个比较都写完整，中间用 && 连起来。
&& 读作“并且”。

小测：哪个和 !(score >= 60) 一样？

读报错：&& 后面少了什么？

score.cpp（只阅读）
    if (score >= 60 && < 90) {
7:24: error: expected primary-expression
before '<' token

expected 的意思是：这里本来应该有东西。

< 的前面缺了要比较的数。要写成 score < 90。

这道题里，&& 的两边都要写成完整的比较。

读报错：括号要包住整个条件

score.cpp（只阅读）
    if (score >= 60) && (score < 90) {
7:25: error: expected identifier
before '(' token

if 的条件写在一对圆括号里。第一对括号关上，条件就结束了。

后面的 && 不在条件里，程序就看不懂了。

要在最外面再包一层：if (score >= 60 && score < 90) {
Dev-C++ 显示的文字可能略有不同，还是先找行号和 error。

Q1&& 和 || 差在哪里？&& 要两边都成立，|| 只要有一边成立。

Q2为什么不能写 60 <= score < 90？程序先算左边得到 0 或 1，再拿它和 90 比，不是数学里的意思。

Q3!(score >= 60) 的括号为什么不能少？少了括号，! 只管到 score，不是反转整个比较。

先自己说一说，再翻下一步看答案。

速查卡

条件1 && 条件2并且：两边都成立才算成立
条件1 || 条件2或者：有一边成立就算成立
!(条件)不：真变假，假变真
x >= 60 && x < 90区间要拆成两个完整的比较
a && (b || c)要先算的部分用圆括号包起来
