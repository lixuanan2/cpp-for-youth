分数是 0 到 100 的整数。程序要这样回答：

前两课的程序每次都走同一条路。这次程序要先比一比，再看情况选一条路。

六个比较符号

> >=大于，大于等于
< <=小于，小于等于
== !=等于，不等于

>= 要写成两个字符，大于号在前。
比较相等要写两个等号。一个等号是把数放进盒子。

读报错：条件要放进圆括号

pass.cpp（只阅读）
    if score >= 60 {
7:8: error: expected '(' before 'score'

7:8 是第 7 行第 8 个字。

expected 的意思是“本来应该有”：score 前面本来应该有左括号。

if 后面的条件，要用一对圆括号包起来。Dev-C++ 显示的文字可能略有不同。

读报错：大括号要成对

pass.cpp（只阅读）
    }    return 0;
error: expected '}' at end of input

end of input 是文件的末尾。

程序读到最后，还有一个大括号没有关上。

这个程序少了 main 最后的 }。
代码缩进写整齐，左右大括号能不能配成对，一眼就看得出来。
