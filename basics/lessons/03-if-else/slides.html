读报错：条件要放进圆括号

  
pass.cpp（只阅读）


    if score >= 60 {

  
main.cpp:7:8: error: expected '(' after 'if'

  

    

      
7:8 是第 7 行第 8 个字。

      
expected 的意思是“本来应该有”：if 后面本来应该有左括号。

      
if 后面的条件，要用一对圆括号包起来。

    

  

  







  
读报错：大括号要成对

  
pass.cpp（只阅读）


    }
    return 0;

  
main.cpp:12:14: error: expected '}'
main.cpp:4:12: note: to match this '{'

  

    

      
第 12 行是最后一行。expected '}'：读到这里，本来还应该有一个右大括号。

      
note 是提醒，它指着第 4 行的 {：就是这个大括号没关上。

      
这个程序少了 main 最后的 }。
代码缩进写整齐，左右大括号能不能配成对，一眼就看得出来。
