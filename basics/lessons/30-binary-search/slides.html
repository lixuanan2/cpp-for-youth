卡住了？一次看一条提示

  

    
提示 1a[mid] >= x 时，它够高了，先用 ans 记下来。可前面也许还有够高的。

    
提示 2所以记下以后不停，继续往左边找：hi = mid - 1。不够高就往右：lo = mid + 1。

    
提示 3循环条件只写 lo <= hi，找到也不停。用 x 是 120（有两个 120）和 150 各试一次。

  

  









  
说得清吗？

  

    
Q1为什么是 lo = mid + 1，不是 lo = mid？mid 已经看过不对了，不用再留在范围里。
