学完以后，程序能读入一个英文单词，一个字母一个字母地看、数、倒着念。

一个单词，怎么存？

上节课的 char 只能放一个字母。输入 cat，char 只读到 c。

一个单词是一串字母，有点像上上节课的数组：一排盒子，每个盒子放一个字符。

C++ 准备好了这种盒子，叫 string（字符串）。
它能放一整个单词，还知道自己有几个字母。

string：放一个单词的盒子

word.cpp
    string word;    cin >> word;    cout << word.size() << endl;    cout << word[0] << endl;

word.size() 是单词有几个字母。
word[0] 是第一个字母，和数组一样，下标从 0 开始。

用 string 时，程序开头加一行 #include <string>。IDE 里的完整程序已经写好了。

word.size() 是 3，下标只到 2。
最后一个字母是 word[n - 1]，n 是长度。

每个 word[i] 都是一个 char，上节课学的 int(…)、char(…) 和比较都能用。

两个单词一样吗？用 ==

password.cpp
    if (word == "open") {        cout << "Welcome!" << endl;    } else {        cout << "Wrong." << endl;    }

string 可以直接用 == 比较：长度一样，每个字母也都一样，才算相等。
一个单词用双引号，一个字符用单引号。

读报错：单词和字符比不了

password.cpp（只阅读）
    if (word == 'o') {
8:14: error: no match for 'operator==' …

no match 是“对不上”：== 两边一个是 string，一个是 char。

'o' 是一个字符，"o" 才是一个单词。和单词比，要用双引号。
想看第一个字母是不是 o，就写 word[0] == 'o'。

这条报错后面还有很长几行，先看第一行的行号和 error 就够了。

找错：哪一行有问题？

输入 cat，前两行是 3 和 c，第三行却是空的。
