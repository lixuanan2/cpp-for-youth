第 1 个盒子的编号是 0，第 2 个是 1，第 3 个是 2。
编号比“第几个”小 1。

读报错：3 个盒子放 4 个数

three.cpp（只阅读）
    int a[3] = {1, 2, 3, 4};
main.cpp:5:26: error: excess elements in array initializer

excess elements 是“多出来的东西”：大括号里的数比盒子多。

方括号写 3，大括号里最多放 3 个数。少放可以，没放到的盒子是 0。多放不行。

最危险的错：下标越界

out.cpp（只阅读，不要运行）
    int a[3] = {4, 7, 2};    a[3] = 5;

编号只到 2，这里却用了 a[3]，写到了数组外面。

main.cpp:6:5: warning: array index 3 is past the end of the array …

cpp.sh 只给一个 warning（警告），程序照样能运行。
结果说不准：有时看着没事，有时输出怪数，有时程序直接退出。
写下标时自己算清楚：最小是 0，最大是 n - 1。

一次输出整排？不行
