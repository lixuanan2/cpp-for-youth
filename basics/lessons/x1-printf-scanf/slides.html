printf 和 scanf

学完以后，小数想保留几位就保留几位，还会用另一种写法读入和输出。

10 除以 3，只想要 3.33

第 2 课讲过：有 10.0 这样的小数参加，除出来才有小数。
可是 cout << 10.0 / 3 输出的是 3.33333，后面一长串。

算平均分、算价钱，常常只要保留两位。
这节课学一种新的输出写法 printf，想留几位就留几位；再学和它配对的读入写法 scanf。

total.cpp



  

    
单价是小数，放进 double；个数是整数，放进 int。

    
scanf 读 double 要写 %lf，读 int 写 %d，顺序和输入一样。

    
3.5 × 4 = 14，保留两位输出 14.00。
printf 输出 double 写 %f 就行。

cout 也能保留几位

  
cout.cpp


    double x = 10.0 / 3;
    cout << fixed << setprecision(2) << x << endl;

  

    
setprecision(2) 是保留两位，前面的 fixed 表示按小数点后面数。
要在开头加 #include <iomanip>。写一次，后面 cout 出来的小数都保留两位。

    
printf 和 cout 都能保留几位，用哪一种都行。
